# Stage 0｜官方參考與技術版本假設（2026-11-18 核對）

| 主題 | 來源 | Stage 0 的使用方式 |
|---|---|---|
| Firebase CLI | https://firebase.google.com/docs/cli | Firebase CLI 目前文件要求 Node.js 18 或以上；基準用 Node 22；不宣稱官方最新版本固定不變 |
| Firebase Emulator | https://firebase.google.com/docs/emulator-suite/install_and_configure | 供 Stage 2 設置本機測試；Java 需求與特定 emulator 版本須於安裝時再核對 |
| Supabase CLI 本機開發 | https://supabase.com/docs/guides/local-development/cli-workflows | Windows 一般使用 Docker-compatible runtime；本地替代方案需另評估，不把「可免 Docker」直接推廣到 Windows |
| Supabase Runtime 選項 | https://supabase.com/docs/guides/local-development/docker-and-native-runtimes | 部分平台提供實驗性 native runtime；不假設本專案 Windows 已可用 |
| GitHub Actions Node | https://github.com/actions/setup-node | 由維護者檢查 Starter Kit v1.2 的既有 CI，再採用 Node 22 |

本包 **沒有**安裝、固定 Firebase CLI／Supabase CLI 最新版本，且不包含兩套候選的 lockfile。等 Stage 2/3 實際安裝時，須在獨立分支記錄精確版本、映像 digest、移轉紀錄、授權政策與成本資料。
